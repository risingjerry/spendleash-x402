# Security

SpendLeash is hackathon software on a testnet. It has not been audited. Don't use it with real funds.

Report vulnerabilities privately through GitHub's **Report a vulnerability** (Security tab → Advisories), not in a public issue.
In scope: anything that lets a payment settle outside a leash (cap, expiry, allowlist, revoke, signature, replay), or lets
anyone other than the owner withdraw, revoke or edit a session.
